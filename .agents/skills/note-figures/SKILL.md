# 笔记配图

先看下面的“选画法”：时间线、方框加箭头的流程和分子结构直接在正文写数据（`toolbox/recipes/figures.md`、`docs/content.md`），不出图；结构式在预览里报原子重叠、压在键上时，用 `npm run molecule:layout` 生成坐标写回 `smiles`。其余的图按本页出图。

一张图一个 prompt，一个 prompt 交给一个 Codex worker。worker 不知道仓库和笔记，图需要的上下文全部写在 prompt 里。读者只看到图；prompt 随图发布到内容库，网站不提供（契约见 `docs/content.md` 的图片段落）。

## 选画法

| 图的类型                                    | 画法                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 数据图：曲线、坐标、刻度、数值点            | 用 matplotlib 或 PIL 画                                                                                                              |
| 示意图：机制、循环、路线、器官、结构关系    | 用生图工具（imagegen）生成，不用代码绘制                                                                                             |
| 结构对比：等排、氟扫描、软点、SAR、骨架跃迁 | imagegen，prompt 给出每个分子的 SMILES 和高亮位置                                                                                    |
| 时间线、一条主干带分支的流程                | 在正文写 timeline / flow 围栏（`docs/content.md`），模板见 `toolbox/recipes/figures.md`，用 `npm run content:preview` 看图并清零警告 |
| 判断树、漏斗、带图标的流程                  | 能用节点与连线表达的先写 flow 围栏；需要图标、漏斗形状或空间关系时，两种画法各派一个 worker，验收后择优                              |
| 历史场景、人物、器物、文献页                | imagegen 钢笔淡彩插画，视觉风格段换成下文“历史插画”的写法，图注标“插画”                                                              |

示意图每个元素只放短标签加一两个关键数值，解释留给正文。

## 能力边界

- prompt 第一句写明工具；示意图不用手写 SVG。
- 数据图写明每个轴的固定范围和刻度。
- 不写“画不出就画空框”这类退路；要求完整结构式。桥环多环按环逐个列出原子与连接。
- 结构式先用 RDKit MolDraw2D 的 ACS 1996 模式（`SetACS1996Mode`）按 SMILES 出参考图，统一朝向并对照 ChemDraw 确认，再让 imagegen 按参考图重画；要求每根键的位置、角度和标签写法一致，改动了键或标签就用 RDKit 版。
- 桥环、笼状分子用 imagegen 结构图，不用 molecule 围栏。
- 代码画图要求不加标题、不用破折号、用 wqy-zenhei 原样输出全角标点。
- imagegen 改字要求整段标签擦掉重写，生僻字改用 PIL 以 wqy-zenhei 重写整行。
- 配色跑偏而结构无误时，用 PIL 按色相映射回深灰与橙。
- 非欧洲人物在 prompt 写明；占位描述按实物写。

## 写 prompt

prompt 写内容、数值、要点和使用环境，不指定图片格式。结构依次是：

1. 一句话说明工具和画什么，加 `文件名：<name>`（不带扩展名）。
2. 内容：要画的元素与精确数值。数据图写清横纵轴、刻度、范围、要标注的点；示意图写清元素、连接顺序和相对位置。
3. 要点：读者一眼要看出的结论，以及容易画错的地方；方向、增减和连接关系必须自洽。
4. 下面三段固定文字，原样附在最后：

```text
使用环境：这张图放在一个中文学习网站的笔记正文里，读者是在电脑前读药物化学入门笔记的成年学习者（有化学背景、刚开始接触药化）。页面是浅色学术阅读风格：背景暖白、深灰正文、正文栏宽约 720 像素，图按栏宽显示，也要能在手机（约 390 像素宽）上缩小后看清主要信息。读者只看到这张图和正文，看不到这段说明，所以图里所有文字都要自洽。图中文字用简体中文，科学符号保持原样。数值必须与上面给出的完全一致，不要增加这里没有给出的数值或结论。

视觉风格：像教科书或学术综述里的插图，不是科普海报。背景色 #faf8f3（与页面相同的暖白），不要纯白底；细线条，扁平，无渐变、无阴影、无卡通表情；深灰为主色，主体用低饱和的冷色（青绿）系，只用一种暖色（橙）做强调。中文用无衬线字体，正常字重为主，只有极少数关键词加粗；不要大号标题。横向构图，宽高比在 4:3 到 16:9 之间；按 720 像素宽显示时最小的文字仍清晰可读。图里只写短标签和数值，不写成段的说明。

交付：在当前目录生成一张图片文件，文件名用上面给出的名字（扩展名由你按图片类型决定）。完成后用一句话说明文件名和你做了什么。
```

历史插画的“视觉风格”段用下面这段替换（使用环境和交付两段照旧）；文件页只写正文或史料逐字给出的文字，其余画成看不清的细字行；人物面部简略，不追求肖像相似：

```text
视觉风格：历史读物里的钢笔淡彩插画，不是照片，也不是油画或海报。细而均匀的深棕灰钢笔线描，线条清楚，交叉排线表现明暗；上面一层低饱和的水彩淡彩：灰青绿、暖灰、少量赭石，全图最多一处橙色强调。背景是平整的暖白纸色 #faf8f3，不要做旧、污渍、折痕、撕边或相框。不要照片质感、景深虚化、胶片颗粒和逆光光晕。构图简洁，主体居中，留白充足。横向构图，宽高比在 4:3 到 16:9 之间。图中文字很少：只在需要时写短标签，中文用无衬线字体；文件上的外文按给出的原文写。
```

## 派发

用交互式 Codex，不用 `codex exec`；prompt 自足，互不依赖的图可以并行。绘图依赖用 `heavy uv run --no-project --with`，不用 `pip install`。具体命令见项目 AGENTS.md 的配图派发段。

## 验收

- 数据图：按坐标轴换算像素，逐个核对数值点、刻度标签和区间标注的位置。
- imagegen 图：逐字核对每个标签和数值，再看箭头方向、标签归属和元素的相对位置。修改版重点核对改动区域，再确认其余部分没有被带动。用 PIL 把图切成四块各放大两倍逐字读；可疑的字单独裁出放大，用 PIL 以 wqy-zenhei 渲染正确字和疑似错字，与图中的字并排比对。
- 分子结构式：prompt 逐字复制正文 molecule 围栏中的 SMILES，并写明要高亮的原子或基团。验收时用项目的 `@rdkit/rdkit` 把同一 SMILES 渲染成参考图，逐个核对环、原子、取代位置和链长；有楔形/虚线键的手性中心按 CIP 规则从图上推出 R/S，与正文给出的构型比对。没有 SMILES 的中间体和衍生物只用文字框，不画结构。
- SVG：用项目的 Playwright 经 `heavy` 在浏览器按 720px 宽渲染后再看，不用 cairosvg。
- 看整图在正文栏宽和手机宽下的可读性，以及风格是否和站点一致。
- 科学关系按正文核对，不只看标签。

## 修改

- 小修（位置、箭头、标签、遗漏）：把意见发回同一个 worker；imagegen 图在现有图上局部编辑，只改指出的地方。同时把同样的文字追加到该图 prompt 文件末尾，记为“修改 N：…”。worker 已关闭时，在同一 cwd 恢复会话。
- 重画：初稿整体偏离或第二轮小修仍不合格时，结束原 worker，把问题写进 prompt 正文，新开 worker 重画。
- 换画法：新开 worker，新写一份 prompt，把已有修改并入正文；新 worker 只凭 prompt 出图。
- 验收通过后才结束 worker，并清理预览图和脚本。

## 发布

图复制到内容目录 `notes/<dir>/assets/<file>`，prompt 复制到 `notes/<dir>/prompts/<file>.md`（`<file>` 是带扩展名的图片文件名）；正文写 `![说明](assets/<file>)`；结构图画了的分子从正文的 molecule 围栏里删掉，图放在原围栏的位置，同一个分子不出现两次；然后按 `docs/content.md` 用内容命令发布。prompt 文件的内容就是最后交给 worker 的完整 prompt，含全部“修改 N”。
